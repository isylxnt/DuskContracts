# Permissions

Player-default permissions: `duskcontracts.use`, `.browse`, `.create`, `.assassination.create`, `.deliver`, `.claim`, `.cancel.own`, `.private.create`, and `.notifications`.

Operator-default bypasses: `duskcontracts.bypass.cooldown`, `.bypass.limits`, `.fulfill.own`, and `.assassination.bypass-farming`.

Administrator nodes: `duskcontracts.admin`, `.admin.reload`, `.admin.inspect`, `.admin.cancel`, `.admin.recovery`, and `.admin.stats`. The parent grants all administrator children by default to operators.
